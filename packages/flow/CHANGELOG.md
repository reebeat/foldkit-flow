# @tsukuri/flow

## 0.1.0-alpha.0

### Minor Changes

- The first alpha of `@tsukuri/flow`: a node-based graph UI for Foldkit on `@xyflow/system`. Pan and zoom, drag nodes, connect and reconnect handles with validation, compound nodes, box selection, minimap, controls, fit view and keyboard control with ARIA roles; the xyflow attribution link is on by default.
